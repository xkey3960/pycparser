# 设计文档：指针与地址模型（MEM-1）

> 问题：`&`/`*`/`->` 目前是**引用语义**过渡（`&x` 返回对象本身），标量写回无效、
> 指针算术不真实、`p[i]`/`NULL`/指针比较缺失。正式化需引入**内存地址模型**。
> 现状基线：lab/learning `8b65257`（MEM-2 栈帧已完成，StackFrame 提供帧隔离）

---

## 一、现状：引用语义的过渡实现及其局限

`&x`（`_address_of`）对变量返回**对象本身**（Python 引用），`*p`（`_deref`）对
int 读堆字节、对其他返回自身。已验证可用：`pa = &a; pa->x = 1` 写回 a、函数指针、
`printf("%llx", &A)`（对象 id 作地址）。

**局限**（TODO.txt MEM-1 罗列）：

| 能力 | 现状 | 问题 |
|---|---|---|
| `&x` 标量 | 返回 int 拷贝 | **写回无效**：`int *p=&x; *p=5` 改不到 x（Python 不可变） |
| `*p` 解引用 | int=堆读字节 / 对象=自身 | 标量指针不可写；无类型感知 |
| 指针算术 | `p+1` 纯数值 | 不按元素大小（`int*` 应 +4） |
| `p[i]` | ArrayRef 只认 list | 指针下标不可用 |
| `NULL` | 无 | 无 |
| 指针比较 | 无 | `p == q` 无地址语义 |
| `p->f` 写 | 靠对象引用 | 标量/数组元素指针不可用 |

## 二、设计：Address 内存地址模型

### 2.1 Address 类（核心）

```python
class Address:
    """内存地址：定位存储槽 + 字节偏移 + 元素类型（指针算术用）。"""

    __slots__ = ("loc", "offset", "elem_type")

    def __init__(self, loc, offset=0, elem_type=None):
        self.loc = loc          # ('var', scope, name) | ('list', list, idx) | ('member', obj, field)
        self.offset = offset    # 字节偏移（指针算术）
        self.elem_type = elem_type   # 指向元素类型（CType），算术步长 = sizeof
```

- **loc 定位**：`&x` → `('var', g_scope, 'x')`；`&arr[i]` → `('list', arr, i)`；
  `&a.field` → `('member', obj, field)`。解引用按 loc 读写。
- **offset**：`p + n` 生成新 Address（offset += n * sizeof(elem_type)），
  `*p` 时对 loc 目标做成员偏移（struct 成员偏移 / list 索引偏移 / 字节数组偏移）。
- **elem_type**：`&x` 时取 x 的 CType（Scope Symbol.type）；指针算术步长 = `elem_type.sizeof()`。

### 2.2 读写原语（Memory 语义，内联在 Address 方法）

```python
def address_read(addr):
    """*addr 读值：loc 定位到容器，按 offset 取元素。"""
    # ('var', scope, name): 标量/对象本体（offset=0）或字节偏移
    # ('list', arr, base): arr[base + offset/elem_size]
    # ('member', obj, field): obj.get(field)（struct 成员；offset 由布局推进）
    # int 退化：堆地址读字节（cbuiltins）
    # 函数名 str：返回自身（函数指针）

def address_write(addr, value):
    """*addr = v 写值（标量/数组元素/struct 成员均写回原容器）。"""
    # ('var', scope, name) → scope.set(name, value)   ← 标量写回！
    # ('list', arr, base) → arr[base + ...] = value
    # ('member', obj, field) → obj.set(field, value)
```

### 2.3 各操作符接入

| 操作 | 规则 |
|---|---|
| `&x` | 返回 `Address(('var', scope, name), 0, x_type)`；函数名仍返回名字串（函数指针） |
| `*p` | `p` 是 Address → `address_read`；int（堆地址）→ 读字节；其他 → 返回自身（宽松） |
| `*p = v` | lvalue 是 `UnaryOp('*')` → `address_write` |
| `p + n` / `p - n` | Address 操作数 → 新 Address（offset ± n*sizeof）；`p++`/`p--` 同理 |
| `p[i]` | ArrayRef 的 name 求值为 Address → `address_read(Address(offset+i*sizeof))` |
| `p == q` / `p != q` | 比较 `(loc, offset)`；NULL（0/None）与空地址 |
| `p->f` | StructRef 的 name 是 Address → 先解引用得对象再取成员（读/写） |
| `NULL` | 指针上下文 0 → 用 `None` 表示空指针；解引用报错"空指针" |

### 2.4 与既有引用语义的关系

- **struct/union/list 变量**：`&a` 返回 Address；`*pa` 解引用得到 StructValue（仍是对象引用，`pa->x` 读写正常）——**与现状行为兼容**（测试 `ptr_main.c` 不变）。
- **标量**：`&x` 返回 Address（不再是拷贝）→ `*p = 5` 经 `scope.set` 写回 ✅ 新能力。
- **退化保留**：函数名 → str（函数指针）；int → 堆地址（malloc 返回 int，`*p` 读堆字节）。

### 2.5 与 MEM-2 栈帧的配合

`Address.loc = ('var', scope, name)` 中的 scope 是**当前活动帧**。函数返回后该帧
作用域被丢弃 → 悬垂指针（`return &local;`）解引用报"变量未定义"（近似 C 的 UB，
可接受）。MEM-2 的 StackFrame 保证每帧独立，地址不串帧。

## 三、对现有功能的影响

| 现有能力 | 变化 |
|---|---|
| `ptr_main.c`（pa=&a; pa->x=1） | 不变（Address 解引用→StructValue，读写兼容） |
| `fnptr_main.c`（函数指针） | 不变（函数名→str 路径保留） |
| `printf_pointer.c`（%llx &A） | 需适配：`_printf_arg` 遇 Address → 打印其 id/地址值 |
| malloc 堆（int 地址） | 不变（int 路径保留） |
| `__builtin_va_list` | 不变（int 句柄） |
| 数组 `arr[i]` | 不变（list 路径优先，Address 路径新增） |

## 四、实施步骤

1. `execute.py`：新增 `Address` 类 + `address_read`/`address_write`
2. `_address_of`：ID/ArrayRef/StructRef 返回 Address（带类型与偏移）
3. `_deref`：Address → address_read
4. `ExeAssignment._set_lvalue`：`UnaryOp('*')` lvalue → address_write
5. `ExeBinaryOp`：`+`/`-` 检测 Address 操作数（指针算术）；`==`/`!=` 比较地址
6. `ExeArrayRef`：name 是 Address → 指针下标
7. `ExeStructRef`/`_set_lvalue` StructRef：name 是 Address → 先解引用
8. `_p_plus_plus`/`_p_sub_sub`：Address 步长算术
9. `cbuiltins._printf_arg`：Address → 地址值（id 的十六进制）
10. 测试：标量写回（`int x; int *p=&x; *p=5`）、指针算术（`int arr[3]; int *p=&arr[0]; p[1]`）、
    `->` 写 struct 成员、NULL 解引用报错、指针比较、`p++`

## 五、验收

- ✅ `int x=0; int *p=&x; *p=5;` → x==5（**标量写回**，之前做不到）
- ✅ `int arr[3]; int *p=&arr[0]; *(p+1)=7;` → arr[1]==7（**指针算术按元素大小**）
- ✅ `pa=&a; pa->x=1` 仍工作（struct 引用兼容）
- ✅ 函数指针、malloc 堆、va_list 零回归
- ✅ NULL 解引用明确报错；指针比较可用
